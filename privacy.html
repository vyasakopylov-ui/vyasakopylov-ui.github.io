Политика конфиденциальности ytvault

ytvault — личное приложение, которым пользуется только его владелец.

  • Какие данные. С разрешения владельца приложение получает доступ к его аккаунту YouTube только на чтение (scope youtube.readonly) и читает список понравившихся видео и их публичные метаданные.
  • Зачем. Чтобы составить личные заметки о сохранённых видео.
  • Где хранится. В приватных репозиториях и на устройствах владельца. Для описания содержания публичных видео их ссылки передаются в Google Gemini API.
  • Кому передаётся. Никому. Данные не продаются, не публикуются и не используются для рекламы.
  • Как отозвать доступ. В настройках аккаунта Google: myaccount.google.com/permissions.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

ytvault is a personal app used only by its owner. With the owner's consent it gets read-only access to the owner's YouTube account (youtube.readonly) to read the list of liked videos and their public metadata, in order to build the owner's personal notes. Data is stored only in the owner's private repositories and devices; links to public videos are sent to the Google Gemini API to describe their content. Data is not shared, sold, published or used for advertising. Access can be revoked at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
